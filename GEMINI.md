# GEMINI.md

Read `AGENTS.md` first and follow it. It is the single source of instructions for this repo.
Skills are in `skills/`; open a skill's `SKILL.md` and follow it step by step.

Read order at the start of a session (AGENTS.md rules 9–11): `AGENTS.md` → `profile.md` + `workspace.md`
→ `projects/<project>/README.md` → newest `worklog.md` entry → the segment's `open-items.md`,
`decisions.md`, `experiments.md` → its `knowledge.md` → `knowledge/INDEX.md` only if still missing.
End every session with `skills/session-close/`.
