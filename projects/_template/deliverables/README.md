# Deliverables

Finished outputs that people use: reports, dashboards, exports, decks. Name files
`<topic>-<YYYY-MM-DD>.<ext>`. Drafts and one-off query results don't belong here —
they go in the skill's `runs/` folder or stay in chat. Replace an outdated deliverable by
archiving the old one (rule 45), never by silently overwriting it.
