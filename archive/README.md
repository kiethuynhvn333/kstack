# Archive

Superseded records, closed experiments and hypotheses, old worklog entries (older than 7 days, moved
weekly), and files retired by an upgrade (e.g. the v0.3 inbox and mistakes files). Archive rather
than delete, and leave a link from the live file to the archived copy (rule 45). Never treated as
fact and never default-loaded (rules 12, 14). Suggested layout: `archive/<YYYY-MM>/<what>.md`.
