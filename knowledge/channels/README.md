# Channels

One file per ad platform, e.g. `google-ads.md`, `meta-ads.md`, `tiktok-ads.md`. Rule 17: before
analysis or any live change, the agent reads the platform's file for lessons already learned.

Platform features change often. Write what *you* verified, with the date and how (official doc
link or observed account behavior) — rule 29. Never copy a feature claim without that.
